01 / Tentang saya

Dari rasa ingin tahu,
menjadi solusi.

Saya adalah mahasiswa Informatika Universitas Muhammadiyah Malang yang tertarik pada pertemuan antara data, teknologi, dan keuangan.

Bagi saya, data bukan sekadar kumpulan angka. Di dalamnya terdapat pola, konteks, dan cerita yang dapat membantu kita memahami masalah dengan lebih jernih. Saya ingin mempelajari bagaimana analisis data dapat menghasilkan insight dan mendukung pengambilan keputusan, terutama dalam bidang keuangan.

Melalui pembelajaran dan proyek mandiri, saya terus mengasah kemampuan teknis serta cara berpikir analitis. Saya senang mengeksplorasi ide, menyusunnya menjadi aplikasi, dan memperbaiki hasilnya secara bertahap. Tujuan saya adalah mengembangkan solusi yang relevan dengan kebutuhan nyata, mudah digunakan, dan memberi manfaat bagi penggunanya.

Produktivitas / macOS

Browser native macOS yang membantu mengelola tab dan workspace berdasarkan konteks aktivitas. Dikembangkan untuk mendukung penjelajahan yang lebih fokus, terorganisasi, dan nyaman digunakan.

02

Analisis data / iOS

Wluey di GitHub (tab baru)

Aplikasi pencatatan siklus menstruasi dengan analisis pola berbasis kalender. Mengeksplorasi pemodelan statistik, penghalusan data deret waktu, dan estimasi tingkat keyakinan sebagai proyek pembelajaran serta riset.

  • SwiftUI
  • Statistical Modeling
  • Time Series
03

Operasional bisnis / macOS

BrewLedger di GitHub (tab baru)

Aplikasi native macOS untuk operasional kafe dan restoran, mulai dari POS kasir, pencatatan transaksi, dan pengelolaan stok hingga laporan. Menggunakan arsitektur MVVM dan integrasi REST API untuk menghubungkan antarmuka dengan backend.

  • SwiftUI
  • MVVM
  • REST API
