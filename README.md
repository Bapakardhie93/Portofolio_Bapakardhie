## Teknologi

- **HTML5** untuk struktur dokumen dan elemen semantik.
- **CSS3** untuk layout Grid dan Flexbox, tipografi, warna, serta media queries.
- **Lucide Icons** sebagai aset SVG lokal.

Seluruh tampilan berjalan tanpa JavaScript, framework CSS, proses build, atau dependensi yang perlu diinstal. Foto tampil hitam putih menggunakan filter CSS; file foto aslinya tetap tersimpan di folder aset.

## Instalasi dan Menjalankan

### Persyaratan

Gunakan browser modern seperti Chrome, Firefox, Safari, atau Edge. Git diperlukan jika mengunduh repositori melalui terminal.

### Menggunakan Git

1. Clone repositori:

   ```bash
   git clone https://github.com/Bapakardhie93/Portofolio_Bapakardhie.git
   ```

2. Masuk ke folder proyek:

   ```bash
   cd Portofolio_Bapakardhie
   ```

3. Buka file `index.html` menggunakan browser. File dapat dibuka langsung dari Finder atau File Explorer dengan klik dua kali.

   Pada macOS, file juga dapat dibuka melalui terminal:

   ```bash
   open index.html
   ```

   Pada Windows Command Prompt:

   ```bat
   start index.html
   ```

   Pada Linux desktop:

   ```bash
   xdg-open index.html
   ```

### Tanpa Git

1. Buka [halaman repositori](https://github.com/Bapakardhie93/Portofolio_Bapakardhie).
2. Pilih **Code > Download ZIP**.
3. Ekstrak ZIP dan buka `index.html` di browser.

Tidak perlu menjalankan `npm install` atau menyalakan server lokal. Pertahankan `index.html`, `style.css`, dan folder `assets` dalam susunan aslinya agar stylesheet, foto, dan ikon dapat dimuat.

## Struktur Folder

```text
Portofolio_Bapakardhie/
|-- index.html          # Struktur dan isi portofolio
|-- style.css           # Gaya visual dan layout responsif
|-- README.md           # Dokumentasi proyek
|-- .gitignore          # File lokal yang tidak diunggah
\-- assets/
    |-- profile.png     # Foto profil
    \-- icons/
        |-- arrow-down-right.svg
        |-- arrow-right.svg
        |-- arrow-up-right.svg
        |-- arrow-up.svg
        \-- LICENSE     # Lisensi ikon Lucide dan Feather
```

## Menyesuaikan Konten

- Edit `index.html` untuk memperbarui profil, pendidikan, proyek, dan kontak.
- Edit variabel warna di bagian `:root` pada `style.css` untuk mengubah palet.
- Ganti `assets/profile.png` untuk memperbarui foto, atau sesuaikan atribut `src` pada elemen foto jika menggunakan nama file lain.
- Buka kembali atau refresh halaman di browser untuk melihat hasil perubahan.
